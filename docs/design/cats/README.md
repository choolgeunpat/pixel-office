# Cat sprites

The office cats (`public/assets/cats/`) are **placeholders** generated by `tools/cats/make_cats.py`
(side view, 40×32 frames: walk, sit, wash, sleep, stretch, jump). The five breeds follow the
reference sheet — 1 Grey & White, 2 Black, 3 White & Grey Tabby, 4 Cream, 5 Calico.

To use the real art from the reference sheet instead:

1. Put the original sheet file here, e.g. `docs/design/cats/reference-cats.webp` (a screenshot loses detail).
2. Cut the frames the same way `tools/characters/` does for the people (key out the panel colour,
   area-average to the shared pixel density) into `public/assets/cats/<breed>.png`.
3. Keep `public/assets/cats/metadata.json` (`frameWidth`, `frameHeight`, `anchor`, and one row per
   animation: walk, sit, wash, sleep, stretch, jump). `public/office/cats.js` needs nothing else.
   Missing animations can fall back to `sit`.
